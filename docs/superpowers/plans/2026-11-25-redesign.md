# Redesign Blog-App – Umsetzungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die Blog-App bekommt durchgehend den Look „Modern & dunkel“ (Entwurf B) mit funktionierendem Hell-Modus, ohne dass sich Funktionen ändern.

**Architecture:** Ein zentrales MUI-Theme (`src/theme.js`, Funktion `getTheme(mode)`) legt Farben, Schrift, Rundungen und das Standard-Aussehen der Bausteine fest. Danach werden die Bausteine Seite für Seite auf das Theme umgestellt: Feste Farbwerte fliegen raus, und der Aufbau wird an Entwurf B angepasst.

**Tech Stack:** React 18, MUI v5 (`@mui/material`, `@mui/icons-material`), Create React App, Schrift Inter (Google Fonts per `<link>`).

**Spec:** `docs/superpowers/specs/2026-11-25-redesign-design.md`

## Global Constraints

- Keine neuen npm-Bibliotheken.
- Keine Änderungen an Logik, Redux, Hooks, API-Aufrufen oder Routen. Nur Aussehen und Beschriftungen.
- Alle Texte der Oberfläche auf Englisch.
- Eine Akzentfarbe: Dunkel `#5b8def`, Hell `#3567d6`. Einzige Ausnahme: Das gelikte Herz nutzt `error.main`.
- Dunkel-Werte: Hintergrund `#0f141a`, Flächen `#161d26`, Rand `#232c37`, Text `#e6e8eb`, Nebentext `#8b95a1`.
- Hell-Werte: Hintergrund `#f6f7f9`, Flächen `#ffffff`, Rand `#e3e6ea`, Text `#111827`, Nebentext `#5b6472`.
- Außerhalb von `src/theme.js` gibt es **keine** festen Farbwerte (`#…`, `"red"`, `"grey"` usw.). Farben kommen nur aus dem Theme (`primary.main`, `text.secondary`, `divider`, `error.main`, `background.paper` …).
- Dunkel ist der Standard, und der Schalter in der Navigationsleiste bleibt.
- Nach jeder Aufgabe: `npm run build` ohne Fehler, Sichtprüfung auf http://localhost:3000 in **beiden** Modi, danach ein Commit auf `feature/redesign`.
- Es gibt keine Test-Bibliothek im Projekt, und neue sind verboten. Die Prüfung erfolgt deshalb über Build, `grep`-Prüfungen und Sichtprüfungen mit fest beschriebenem Ergebnis.

## Review Focus

1. **Heller Modus auf jeder Seite:** Kein dunkler Text auf dunklem Grund und keine grauen Reste des alten Designs. Wird in jeder Aufgabe in Schritt „Sichtprüfung“ mit dem Schalter geprüft.
2. **Login/Registrieren folgen dem Schalter:** Heute erzwingen sie ein eigenes Standard-Theme (`createTheme()` in `Login.jsx:16`, `Register.jsx:13`). Wird in Aufgabe 6 geprüft.
3. **Karten mit langen Titeln, fehlendem Bild oder fehlender Kategorie:** Alle Karten bleiben gleich hoch, nichts läuft über, und ohne Kategorie erscheint kein Etikett. Wird in Aufgabe 3 geprüft.
4. **Nicht eingeloggt auf der Startseite:** Die Karten zeigen sich ohne Absturz, Herz und Kommentar führen zu `/login`. Wird in Aufgabe 3 geprüft.
5. **Handy-Breite (375 px):** Das Menü-Symbol erscheint, „+ New Post“ ist erreichbar, und die Karten stehen in einer Spalte. Wird in Aufgaben 2 und 3 geprüft (Browser-Entwicklertools, Gerätemodus).

### Task 1: Zentrales Theme und Schrift

**Files:**
- Create: `src/theme.js`
- Modify: `src/App.js` (eigenes `createTheme` ersetzen)
- Modify: `public/index.html` (Inter-Link, `theme-color`)

**Interfaces:**
- Produces: `getTheme(mode: "dark" | "light") => Theme` (Default-Export nicht nötig, benannter Export `getTheme`). Später genutzte Theme-Schlüssel: `palette.primary.main`, `palette.background.default`, `palette.background.paper`, `palette.divider`, `palette.text.primary`, `palette.text.secondary`, `palette.error.main`, `shape.borderRadius` (= 12).

- [ ] **Schritt 1:** In `public/index.html` im `<head>` Inter laden (Google Fonts, Gewichte 400, 500, 600, 700, mit `preconnect`) und `theme-color` auf `#0f141a` setzen.
- [ ] **Schritt 2:** `src/theme.js` mit `getTheme(mode)` anlegen. Werte aus den Global Constraints. Dazu `typography.fontFamily` = `"Inter", system-ui, -apple-system, "Segoe UI", Roboto, sans-serif` und `shape.borderRadius: 12`. Standard-Aussehen über `components`:
  - `MuiPaper`: `backgroundImage: "none"`
  - `MuiCard`: kein Schatten, 1px Rand in `divider`
  - `MuiButton`: `disableElevation`, `textTransform: "none"`, `fontWeight: 600`
  - `MuiAppBar`: `elevation 0`, Hintergrund `background.default`, Textfarbe `text.primary`, untere Linie in `divider`
  - `MuiChip`: kleine Pille
- [ ] **Schritt 3:** In `src/App.js` `createTheme({...})` durch `getTheme(prefersDarkMode ? "dark" : "light")` ersetzen. `prefersDarkMode` startet weiter mit `true`.
- [ ] **Schritt 4:** `npm run build`. Erwartet: „Compiled successfully“ oder nur die bekannten 3 Warnungen zu unbenutzten Variablen.
- [ ] **Schritt 5: Sichtprüfung.** Startseite dunkel mit Hintergrund `#0f141a`, Schrift Inter (in den Entwicklertools unter „Computed → font-family“ prüfen). Schalter → heller Hintergrund `#f6f7f9`.
- [ ] **Schritt 6:** Commit `Redesign: zentrales Theme (dunkel/hell) und Schrift Inter`.
